# برنامک فراهوش
نسخه اولیه وب‌سایت فارسی راست‌چین دوره‌های فراهوش.

## انتشار
فایل `index.html` را در مخزن GitHub بارگذاری کنید و سپس از Settings > Pages انتشار را فعال کنید.

## توجه
فرم ثبت‌نام در این نسخه صرفاً نمایشی است و اطلاعات را ذخیره یا ارسال نمی‌کند. برای ثبت‌نام واقعی، باید سرویس ثبت اطلاعات و روش ارتباط/پرداخت به آن متصل شود.
